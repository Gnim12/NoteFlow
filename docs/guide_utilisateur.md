# 📘 Guide utilisateur — NoteFlow

Guide succinct des principales fonctionnalités de l'application.

---

## Se connecter

- **Créer un compte** : email + mot de passe (6 caractères minimum), ou
  **Continuer avec Google**.
- **Mot de passe oublié** : saisir son email pour recevoir un lien de
  réinitialisation.
- Les données sont automatiquement associées à votre compte et retrouvées
  sur tout appareil où vous vous reconnectez.

## Gérer ses notes

- **Nouvelle note** : bouton **+** sur l'accueil. Titre et description sont
  obligatoires.
- **Modifier** : appuyer sur une note, ou passer par le menu ⋮ → Modifier.
- **Épingler / Favori** : menu ⋮ sur une note, ou depuis l'écran de
  modification.
- **Supprimer** : menu ⋮ → Supprimer. La note part dans la **Corbeille**
  (Paramètres → Corbeille) — restaurable ou supprimable définitivement.
- **Historique** : dans l'écran de modification d'une note, icône 🕐 en haut
  à droite pour revoir et restaurer une version précédente.

## Organiser

- **Catégories** : Paramètres → Catégories, pour créer des catégories
  colorées. Filtrage par catégorie sur l'accueil (chips sous la barre de
  recherche).
- **Tags** : dans l'écran de modification d'une note, section "Tags". La
  recherche de l'accueil trouve aussi les notes par tag.
- **Recherche et tri** : barre de recherche sur l'accueil, icône de tri à
  droite pour changer l'ordre (récentes, anciennes, dernière modification,
  titre, favoris, couleur).

## Pièces jointes et localisation

- Dans l'écran de modification d'une note : section "Pièces jointes" (➕)
  pour ajouter une image (galerie/appareil photo) ou un fichier.
- Section "Localisation" pour associer un lieu à une note : position
  actuelle, recherche par nom, ou sélection sur la carte. Bouton "Ouvrir"
  pour lancer une application de navigation.

## Rappels

- Section "Rappels" dans une note : ajouter une date/heure et, si besoin,
  une récurrence (quotidien, hebdomadaire, mensuel, ou personnalisé).
- Taper sur la notification reçue ouvre directement la note concernée.
- Vue d'ensemble : Paramètres → Rappels.

## Partager une note

- Dans l'écran de modification d'une note : section "Partage" → indiquer
  l'email d'un utilisateur NoteFlow et choisir lecture seule ou
  lecture/écriture.
- Retirer l'accès à tout moment depuis la même section.
- Notes reçues : Paramètres → "Notes partagées avec moi" (nécessite une
  connexion Internet).

## Fonctionnement hors connexion

- Créer, modifier, supprimer des notes fonctionne sans connexion.
- Un badge sur l'accueil indique l'état de synchronisation : vert
  "Synchronisé", orange "modifications en attente" (elles seront envoyées
  automatiquement dès que la connexion revient).
- Les pièces jointes, catégories et rappels se synchronisent aussi
  automatiquement, en meilleur effort.
- Les notes partagées avec vous nécessitent une connexion (elles ne sont pas
  mises en cache localement).

## Paramètres utiles

- **Mode sombre** : bascule en haut de l'écran Paramètres.
- **Exporter les notes (PDF)** : génère un document récapitulatif.
- **Mon profil** : modifier nom, email, mot de passe, photo.
